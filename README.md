# Coal Ash Pond Contamination / Groundwater Transport Screening Model

A Python model estimating projected contaminant leaching and groundwater
transport from coal fly ash ponds, organized by U.S. Census region, at 5/10/20 years
(and more) Built from literature review of EPA/Site avarages/Reigonal data.

## READ THIS FIRST — what this model is and isn't

**This is a screening/planning-level model, not a site-specific regulatory
determination.** It uses one analytical (closed-form) 1-D transport solution,
regional/literature default parameters, and a handful of illustrative
receptor distances — not a calibrated, site-specific numerical groundwater
model built on real monitoring-well data. Data within this model are a guideline of potential leaching, not exact values.
A real CCR-rule compliance determination requires the pond inventory, laboratory leaching data (EPA LEAF), a real
monitoring-well network, a statistical framework, and a groundwater model

## Quickstart

```bash
pip install -r requirements.txt
python3 tests/test_core.py     
python3 run_model.py          
```

Outputs land in `outputs/tables/*.csv` and `outputs/plots/*.png`.
`outputs/tables/mass_balance_check.csv` should be prioritized — every one of the 756 (region × metal × tier × year)

file again before trusting anything else.

## The calculation sequence

ash mass -> contaminant mass in ash -> leaching fraction -> leachable mass
   -> leachate concentration (source boundary, C0)
   -> vertical infiltration through ash+soil (Darcy, layered-media harmonic mean)
   -> horizontal Darcy flow in the aquifer -> pore-water velocity
   -> dispersion (Xu & Eckstein 1995 field-scale estimator)
   -> retardation (Kd, EPA screening defaults)
   -> 1-D retarded transport solution -> C(distance, time)
   -> mass-balance closure check
   -> regulatory exceedance ratio
```

pH/redox chemistry, regional scenarios, and Monte Carlo uncertainty are
layered on top of this core, per this project's own stated build order.


## Key equations actually implemented

| Quantity | Equation | Module |
|---|---|---|
| Initial contaminant mass | `M0 = M_ash * C_solid` | `source_term.py` |
| Leachable mass | `M_L = M0 * f_L` | `source_term.py` |
| Kinetic source depletion | `M(t) = M0 * exp(-k_L t)`, `k_L` calibrated to match the simple model's total (see docstring — no calibration data existed to fit `k_L` independently) | `source_term.py` |
| Darcy flux / flow | `q = Ki`, `Q = KAi` | `flow.py` |
| Pore velocity | `v = q / n_e` | `flow.py` |
| Retardation factor | `R = 1 + (ρ_b·Kd)/n` | `sorption.py` |
| Dispersivity (field-scale) | `α_L = 0.83·[log10(L)]^2.414` (Xu & Eckstein 1995) | `transport.py` |
| **Transport** | retarded Ogata-Banks: `C(x,t)/C0 = 0.5[erfc(a) + exp(vx/D_L)·erfc(b)]`, `a=(Rx-vt)/(2√(D_L R t))`, `b=(Rx+vt)/(2√(D_L R t))` | `transport.py` |
| Mass balance | `M0 ≈ M_remaining + M_dissolved + M_sorbed + M_exported` | `mass_balance.py` |
| Exceedance ratio | `ER = C_predicted / C_limit` | `regulatory.py` |

The transport substitution (`v_eff=v/R`, `D_eff=D_L/R`) was verified
**symbolically with sympy**, not just hand-derived once — see
`tests/test_core.py::test_transport_formula_derivation`. The naive formula
overflows in double precision at realistic field distances (`exp(vx/D_L)`
explodes while `erfc(b)` vanishes); this is fixed with SciPy's `erfcx`
(scaled complementary error function), the same trick used in EPA/USGS
screening codes, and cross-checked against the naive computation at
parameter values small enough not to overflow.

**Decay is not implemented.** `transport.py` raises error

## Variable data and inaccuracies

- **367 CCR-regulated facilities** (state, plant, city, legacy-impoundment
  status) — `US_Coal_Ash_CCR_Facilities_1.xlsx`
- **235 facilities / 675 assessed ponds**, hazard rating + condition
  assessment — `US_Coal_Ash_Pond_Inventory.xlsx`
- **Structured contaminant/leaching reference table** —
  `coal_ash_contaminant_data.xlsx` and `Coal_Ash_Contamination_Data_Sources.docx`:
  **"HONEST GAP"** flags for Chromium, Lead,
  Cadmium, and Mercury, values derived from average values through literature review. 
- **Regional hydrogeology** (soil texture, porosity, K_sat, mean annual
  temperature by Northeast/South/Midwest/West) 





### Data-quality flags carried into every output row

Every scenario result carries `kd_quality`, `leachable_fraction_quality`,
and an explicit `honest_gap_flags` list into `full_results_long.csv` — so a
reader can filter to "only the parts of this table backed by something
better than a screening default" without having to re-derive that
themselves.



## Regions, scenarios, and site geometry

- **Regions**: standard U.S. Census Bureau four-region split
- **Scenario tiers**: `low` (low release / high attenuation), `central`,
  `high` (high release / low attenuation)  
 multipliers on leaching fraction, Kd, hydraulic
  conductivity, and gradient (`scenarios._tier_multiplier`).
- **Site geometry** (pond area, ash thickness, pond head, hydraulic
  gradient)
  `reference_data.py` (40-acre pond ≈ the CCR rule's own regulatory size
  threshold, 6 m ash thickness, 1.81 m median pond head, i=0.01 — labeled
  "assumed," matching this project's own earlier explicit caveat about that
  exact number) 
- **Receptor distances**: 30 m (pond-edge/property-boundary proxy), 150 m
  (nearby monitoring well), 500 m, 1,500 m (~1 mi, distant-well proxy)


## How to plug in real site data

Every screening default lives in `reference_data.py` or is passed as an
explicit argument to `scenarios.run_scenario(...)`. To run a real facility:

```python
result = scenarios.run_scenario(
    region="South", metal="Arsenic", coal_rank="Bituminous", tier="central",
    c_solid_override_mg_kg=<your lab-measured ash concentration>,
)
```

For site-specific hydrogeology (K, gradient, porosity, pond geometry),
either edit `scenarios.default_inputs`/`REGIONAL_PARAMS` directly for a one-
off run, or call the lower-level `flow`/`sorption`/`transport` functions
directly with your own numbers — every function in this package takes plain
floats and has no hidden state.

retardation-factor arithmetic against a hand calculation; Darcy flux and
travel time (0.29 m/yr,
